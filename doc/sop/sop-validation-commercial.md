## 0. Instructions

Ce document sert à **figer les décisions commerciales de Hercule.dev avant toute modification de la landing page**.

Pour chaque question :

- cocher **une seule réponse** lorsqu'il s'agit d'un choix exclusif ;
- cocher plusieurs réponses uniquement lorsque la question le permet explicitement ;
- si aucune réponse ne convient, utiliser `☐ Autre : ________` ;
- ne pas modifier directement le SOP pendant cette étape : les réponses servent de source pour sa prochaine génération.

### Deux types de questions

**[V] Validation** — vérifie si une information actuellement présente dans la documentation est toujours correcte.

**[E] Expansion** — introduit une question qui n'est pas suffisamment définie et doit être tranchée pour obtenir un SOP exploitable.

### Critères économiques de référence

- **MMR cible :** > 1 500 €
- **Churn rate cible :** < 50 %
- **Marge cible :** 60–70 % minimum

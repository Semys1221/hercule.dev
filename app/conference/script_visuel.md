# **SCRIPT VISUEL — HERCULE VSL**

## **RÈGLE GÉNÉRALE**

- Fond noir.
- UI monochrome : blanc, gris, silver.
- Couleurs uniquement lorsqu’elles portent une information.
- Personnages : cercle + arc minimaliste.
- Icônes : géométriques, type Lucide / Vercel.
- Aucun emoji.
- Aucun personnage illustré.
- Aucun gros bloc de texte inutile.
- Les éléments peuvent se déplacer, fusionner, se diviser, disparaître et changer de rôle.
- Les transitions doivent raconter quelque chose.
- `ESPACE` = passage au beat visuel suivant.
- Une scène peut contenir plusieurs beats avant de changer complètement de composition.
- Le Rubik’s Cube est le fil rouge visuel.

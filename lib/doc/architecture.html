Routing Calendly

Attribution prospect → client. Le lien déposé dans Instantly pointe vers un event type de l'org Calendly Hercule. Multi-client par niche via pool router.

Chaîne À construire partout

  1. Prospect niche N
  2. Pool router / round-robin
  3. Client slot actif
  4. Inject calendly_scheduling_url
  5. Sending E1–E3
  6. Book → agenda client

Séparé de l'engine À décider schéma

  • CRM Hercule = table clients
  • Import seulement si le RDV/paiement est vers Hercule
  • Un restaurant booké chez un comptable ≠ client Hercule
  • Engine evergreen — coquille vide standardisée
